Panel Admin (dalam talian)

Kawal fungsi bot bercakap untuk semua pengguna atau untuk anda sahaja. Tiada EXE: terus di Chrome.

  1. Tekan "Buka panel admin".
  2. Di Chrome tekan Pasang sebagai aplikasi (atau ikon pasang di bar alamat) untuk letak pintasan di desktop.
  3. Log masuk dengan akaun admin.
Buka panel admin
Panel admin dipasang melalui Google Chrome sebagai aplikasi sahaja (PWA), tidak perlu fail EXE. Pengguna lain boleh membuka pautan panel tetapi tidak boleh mengubah apa-apa tanpa akaun admin.
