# global-streamer-releases-exe-apps

Halaman muat turun dan panel admin dalam talian (PWA) untuk Global Streamer.
- `index.html` = halaman muat turun. `admin/` = panel admin (dipasang sebagai aplikasi melalui Chrome).
- GitHub Pages: Branch `claude/global-streamer-continuation-bzcbrq`, folder `/ (root)`.
- `firestore.rules` = peraturan Firestore penuh (blok baharu: `config` dan `adminConfig`).
